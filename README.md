# Circuit-Laser-System
Individual Electrical Engineering Project #1. 

## Laser System Overview
This project is a Elegoo-based laser detection system designed and build to be an independent electrical engineering project.

The goal of the project is to design and construct the hardware of the project as well as program the software as well. Tests of the project well ensure that the system fully utilies a laser and sensor operates in ways that the laser mimics the pattern of the user's hand movements.

## Project Status:
In Progress

## Goals

- Detect and measure hand movement
- Process motion data using an Arduino
- Control the movement of a laser using motors/servos
- Reproduce the user's hand movement with the laser
- Test the accuracy and responsiveness of the system
- Document the design, programming, testing, and troubleshooting process
- Develop a functional physical prototype

## Documentation

Circuit diagrams, mechanical designs, Arduino code, testing results, photographs, videos, and a final engineering report will be added as the project progresses.
